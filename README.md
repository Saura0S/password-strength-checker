# 🔐 Password Strength Checker

A simple and interactive **Password Strength Checker** built using **Python (Tkinter GUI)**.  
This tool helps users test and visualize the strength of their passwords based on various parameters like length, character variety, and entropy.

---

## Features
- ✅ Real-time password strength analysis  
- ✅ Visual feedback for **Weak**, **Medium**, and **Strong** passwords  
- ✅ Detects uppercase, lowercase, numbers, and special characters  
- ✅ Clean and lightweight GUI using Tkinter  
- ✅ Easy to use and customize  

---

## How It Works
The strength of the password is calculated based on:
1. **Length** of the password  
2. **Character diversity** — uppercase, lowercase, digits, symbols  
3. **Entropy calculation** for randomness  

The app provides instant visual feedback through color indicators and text.
